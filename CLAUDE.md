# CLAUDE.md

## Project: Dave-in-a-Box (WoozBox)

Self-hosted AI toolbox - chat, image/music/video generation. Monorepo with Docker Compose, one directory per service, vanilla JS frontend.

## Style Rules

- **No em dashes.** Use regular hyphens (-) everywhere - code, comments, docs, commit messages. Never use the Unicode em dash character.
- No emojis unless the user explicitly asks for them.

## Architecture

- Frontend: vanilla HTML/CSS/JS, no build tools, no frameworks. Plain `<script defer>` and `<link>` tags.
- Backend: each service is a single-file FastAPI app (except rag-api which has db.py and indexer.py).
- All JS files share global scope. Load order matters - see `web/index.html` for the script tag sequence.
- CSS is split into 6 files in `web/css/` loaded in numbered order.
- SVG icons use a sprite sheet (`web/icons.svg`) with `<symbol>` + `<use>` pattern.
- IndexedDB CRUD is generated by `createStudioDB()` factory in `web/js/db-helpers.js`.
- LLM system prompts live in `PROMPTS` dicts at the top of `rag-api/main.py` and `media-api/main.py`.

## Key Commands

```bash
docker compose up -d              # Start all services
docker compose build <service>    # Rebuild one service
docker compose logs -f <service>  # Tail logs
```
