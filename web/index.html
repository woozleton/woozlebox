            Prompt Templates
            

              
              
            

          

          
Edit the system prompts used by all LLM features. Changes apply globally for all users.

          

            

              
Prompt Editing Guide

              

                
Template Variables

                
Some prompts support runtime variables that get replaced with real values when the prompt is used. Available variables are listed below each prompt. Wrap variable names in curly braces:

                
{model} - replaced with the active LLM model name
{custom_instructions} - replaced with user-provided instructions

              

              

                
Markdown Formatting

                
Prompts are sent as plain text to the LLM. You can use markdown-style formatting that the model will understand:

                
## Headings - organize sections
- Bullets - list items or rules
[section] - section labels (e.g. [verse], [chorus])

              

              

                
Special Tags

                
Some prompts use special tags that control specific features:

                
<laugh> <sigh> <gasp> - TTS emotion tags (Orpheus voices)
[SAVE_MEMORY:fact] - memory storage directive
[DELETE_MEMORY:fact] - memory removal directive
/no_think - disable model thinking/reasoning

              

              

                
Tips

                
Changes auto-save after you stop typing. Click the preview area to edit, click outside to return to preview. Modified prompts show a pill indicator and can be individually reset. The "Reset All" button reverts every modified prompt to its default.
