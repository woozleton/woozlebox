Key Patterns

No build tools Plain <script defer> and <link> tags. No bundler, no transpiler, no npm. Global scope JS All JS files share the global scope. Functions defined in any file are callable from any other file loaded after it. IndexedDB factory createStudioDB() in db-helpers.js generates CRUD functions (save, load, delete, update) for each studio's IndexedDB store. Shared modals Two shared modals (trash + folder) are reused across image/music/video studios via dynamic onclick assignment. SVG sprites icons.svg contains 34 <symbol> elements. Used via icon("name", size) helper which returns <svg><use> markup. PROMPTS dicts All LLM system prompts are defined as PROMPTS = {} dicts at the top of rag-api/main.py (10 prompts) and media-api/main.py (8 prompts). Single-file services Each backend service is one main.py file. Only rag-api has additional modules (db.py, indexer.py). GPU serialization gpu-manager serializes all /acquire calls via asyncio.Lock. Only one model occupies VRAM at a time (except music which keeps SDXL Turbo for cover art). ES module + importmap avatar.js is the only ES module. An importmap in <head> maps the bare specifiers three and three/addons/ to vendored local files in web/lib/, so TalkingHead and its deps resolve without a bundler. Shared AudioContext avatar.js creates the Web Audio AudioContext early and exposes it as window._ttsAudioCtx. tts.js picks it up lazily on first TTS use, ensuring both share one context so the AnalyserNode can tap TTS audio for lip-sync.

Total codebase: ~5,200 lines of Python across 6 backend services, ~9,780 lines of JavaScript across 18 modules, ~3,292 lines of CSS across 6 files, and ~1,770 lines of HTML.
