Key Patterns

No build tools Plain <script defer> and <link> tags. No bundler, no transpiler, no npm. Global scope JS All JS files share the global scope. Functions defined in any file are callable from any other file loaded after it. Studio API factory createStudioAPI() in studio-api.js generates server-backed CRUD functions (save, loadAll, remove, clear, has) for each studio. Data is stored in SQLite with media files on disk. Shared modals Two shared modals (trash + folder) are reused across image/music/video studios and note taker via dynamic onclick assignment. SVG sprites icons.svg contains 45 <symbol> elements. Used via icon("name", size) helper which returns <svg><use> markup. PROMPTS dicts All 37 LLM system prompts are defined as PROMPTS = {} dicts at the top of rag-api/main.py and media-api/main.py. Defaults are hardcoded; admin overrides are stored in the prompt_overrides SQLite table. The get_prompt(key) helper checks overrides first. The admin prompt editor UI (admin-prompts.js) provides a collapsible accordion editor with auto-save, preview, and per-prompt reset. Single-file services Each backend service is one main.py file. rag-api has additional modules (db.py, indexer.py); tts-llm is supervisor.py (wraps a llama.cpp server, not FastAPI). GPU serialization gpu-manager serializes all /acquire calls via asyncio.Lock. Only one model occupies VRAM at a time (except music which keeps SDXL Turbo for cover art). ES module + importmap avatar.js is the only ES module. An importmap in <head> maps the bare specifiers three and three/addons/ to vendored local files in web/lib/, so TalkingHead and its deps resolve without a bundler. Slash commands registerCommand() in slash-commands.js adds commands to a global registry. 31 commands total - 15 are tagged universal: true and work from any prompt input (chat, image, music, video, code), the other 16 are chat-only. Typing / in any prompt shows a context-filtered autocomplete popup. A shared popup element tracks the active textarea and moves between .prompt-box containers on focus. Shared AudioContext avatar.js creates the Web Audio AudioContext early and exposes it as window._ttsAudioCtx. tts.js picks it up lazily on first TTS use, ensuring both share one context so the AnalyserNode can tap TTS audio for lip-sync.

Monorepo with 10 backend services (rag-api, media-api, gpu-manager, image-api, music-api, video-api, notetaker-api, code-runner, tts-llm, tts-api), 23 JavaScript modules, 6 CSS files, and a single-page HTML shell.
