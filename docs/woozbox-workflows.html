VRAM Workflows

Step-by-step GPU orchestration for each studio mode

Chat

Keeps the target LLM if already loaded, evicts everything else, and coexists with Orpheus TTS when it fits

Switch to Chat
gpu-manager /acquire (chat)
◆ Keep target chat LLM if already loaded
✕ Evict other Ollama models
▼ Unload all gen services
▲ Warm up user's selected chat LLM (if not kept)
● TTS fit check: chat_llm + tts + headroom vs budget
▲ If it fits, load Orpheus via tts-llm supervisor (:5007)
✕ Else evict Orpheus + set tts_blocked_by → TTS requests return 409
Send Message
rag-api /chat
● Embed query via embedding model
● Search vault via ChromaDB
● Stream LLM response
⚠ Auto-play TTS streams directly from tts-api (:5005) - 409 surfaces as toast if blocked

Image Studio

Utility model loads on-demand for inspire/naming, evicted before generation

Switch to Image
gpu-manager /acquire (image)
✕ Evict non-utility LLMs
▼ Unload music-api, video-api, notetaker-api
▲ Load selected image model
Inspire Button
media-api /image/inspire
● Utility LLM loads on-demand
● Returns creative image prompt
Generate
gpu-manager /acquire (image, pre_inference)
✕ Evict ALL Ollama models (including utility)
✓ Image model already loaded
Inference
image-api /generate
● Image model runs diffusion
● Full VRAM available - no contention

Music Studio

Two models coexist - ACE-Step for music + SDXL Turbo for cover art

Switch to Music
gpu-manager /acquire (music)
✕ Evict non-utility LLMs
▼ Unload video-api, notetaker-api
✓ Keep image-api (for cover art)
▲ Load ACE-Step
▲ Load SDXL Turbo (cover art)
Inspire / Name
media-api /music/inspire, /name-song
● Utility LLM loads on-demand
● Returns prompt idea / song title
Write Song
gpu-manager /acquire (songwriting) + media-api /music/write-song
✕ Evict ALL Ollama models (including utility)
▼ Unload all gen services
▲ Warm up songwriting LLM
● Returns style prompt + structured lyrics
Generate
gpu-manager /acquire (music, pre_inference)
✕ Evict ALL Ollama models
▲ Load ACE-Step
▲ Load SDXL Turbo (cover art)
Inference
music-api /generate
● ACE-Step runs audio generation
Cover Art
media-api /music/cover-art
● Utility LLM generates image prompt
● SDXL Turbo renders cover art

Note Taker

whisperX transcription + optional LLM summarization

Switch to Note Taker
gpu-manager /acquire (notetaker)
✕ Evict ALL Ollama models (including utility)
▼ Unload all gen services
▼ Unload tts-llm (Orpheus is on-demand here, not resident)
▲ Load whisperX model
Transcribe
notetaker-api /transcribe
● ffmpeg converts audio to 16kHz WAV
● whisperX transcribes + aligns word timestamps
● pyannote exclusive diarization - one speaker per moment (if enabled)
Auto-Name
media-api /notetaker/name
● Utility LLM generates title from transcript
Summarize (optional)
media-api /notetaker/summarize
● Full LLM loads for quality summaries
● LLM auto-classifies note type (professional, personal, etc.)
● Prompt selected by classified note type
⚠ whisperX stays loaded - coexists with LLM
Play Summary (TTS)
gpu-manager /acquire?service=tts
▲ Supervisor spawns llama-server for Orpheus on demand
● tts-api streams SNAC audio back to the browser
✕ On audio `ended`, frontend fires /release?service=tts to free VRAM

Code Studio

Pair-programming editor - keeps the target coding LLM if already loaded

Switch to Code
gpu-manager /acquire (code)
◆ Keep target code LLM if already loaded
✕ Evict other Ollama models
▼ Unload all gen services
▲ Warm up coding LLM (if not kept)
Generate Code
Ollama /api/chat (multi-turn)
● Multi-turn conversation with system prompt
● SEARCH/REPLACE block parsing for incremental edits
● Optional plan mode, thinking, and permission gating

The utility model loads on-demand when inspire/naming is called. It is always evicted before actual inference via the pre_inference flag on /acquire. Songwriting uses a dedicated VRAM profile that evicts everything before loading the full LLM. Chat, code, and songwriting acquires keep the target LLM if it's already loaded - only other models are evicted. HuggingFace gated repos return HTTP 403 and surface a toast with an accept-terms link. See VRAM_PROFILES in gpu-manager/main.py and .env for model configuration.
