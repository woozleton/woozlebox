VRAM Workflows

Step-by-step GPU orchestration for each studio mode

Chat

Simple - evict everything, load the chat LLM

Switch to Chat
gpu-manager /acquire (chat)
✕ Evict ALL Ollama models
▼ Unload image-api, music-api, video-api
▲ Warm up chat LLM (e.g. qwen2.5:14b)
VRAM Before (example: coming from Image Studio)
qwen3:0.6b 0.4G stable-diffusion-3.5 13.1G
VRAM After
qwen2.5:14b 16.5G
Send Message
rag-api /chat
● Embed query (nomic-embed-text)
● Search vault via ChromaDB
● Stream LLM response
VRAM During
qwen2.5:14b 16.5G nomic-embed-text 0.3G

Image Studio

Utility model loads on-demand for inspire/naming, evicted before generation

Switch to Image
gpu-manager /acquire (image)
✕ Evict non-utility LLMs (e.g. qwen2.5:14b)
▼ Unload music-api, video-api
▲ Load selected image model (e.g. SD 3.5)
VRAM Before (example: coming from Chat)
qwen2.5:14b 16.5G nomic-embed-text 0.3G
VRAM After
stable-diffusion-3.5 13.1G
Inspire Button
media-api /image/inspire
● Calls Ollama with qwen3:0.6b (loads on-demand)
● Returns creative image prompt
VRAM After
qwen3:0.6b 0.4G stable-diffusion-3.5 13.1G
Generate
gpu-manager /acquire (image, pre_inference)
✕ Evict ALL Ollama models (including qwen3:0.6b)
✓ SD 3.5 already loaded - no change
VRAM After
qwen3:0.6b evicted -0.4G stable-diffusion-3.5 13.1G
Inference
image-api /generate
● SD 3.5 runs diffusion (~13GB)
● VRAM spikes during inference, returns to baseline
VRAM During Peak
stable-diffusion-3.5 13.1G base, ~10G peak

Music Studio

Two models coexist - ACE-Step for music + SDXL Turbo for cover art

Switch to Music
gpu-manager /acquire (music)
✕ Evict non-utility LLMs (e.g. qwen2.5:14b)
▼ Unload video-api
✓ Keep image-api (for cover art)
▲ Load ACE-Step 1.5
▲ Load SDXL Turbo (cover art)
VRAM Before (example: coming from Chat)
qwen2.5:14b 16.5G nomic-embed-text 0.3G
VRAM After (~13GB)
ace-step-1.5 6.1G sdxl-turbo 6.6G
Inspire / Name / Write Song
media-api /music/inspire, /name-song
● Calls Ollama with qwen3:0.6b (loads on-demand)
● Returns prompt idea / song title
VRAM After
qwen3:0.6b 0.4G ace-step-1.5 6.1G sdxl-turbo 6.6G
Write Song
media-api /music/write-song
▼ Unloads image-api to free VRAM
● Calls Ollama with qwen2.5:14b (full LLM for quality lyrics)
● Returns style prompt + structured lyrics
VRAM During
qwen2.5:14b 16.5G ace-step-1.5 6.1G sdxl-turbo unloaded
Generate
gpu-manager /acquire (music, pre_inference)
✕ Evict ALL Ollama models (qwen2.5:14b, qwen3:0.6b, etc.)
▲ Reload SDXL Turbo if unloaded by write-song
✓ ACE-Step already loaded
VRAM After
qwen2.5:14b evicted -16.5G ace-step-1.5 6.1G sdxl-turbo 6.6G
Inference
music-api /generate
● ACE-Step runs audio generation
Cover Art
media-api /music/cover-art
● Utility LLM generates image prompt
● SDXL Turbo renders 512x512 cover (4 steps)
VRAM During
qwen3:0.6b 0.4G ace-step-1.5 6.1G sdxl-turbo 6.6G - needed for cover art

Video Studio

Wan 2.1 needs all VRAM - everything else is evicted

Switch to Video
gpu-manager /acquire (video)
✕ Evict ALL Ollama models (including utility)
▼ Unload image-api, music-api
▲ Load Wan 2.1 T2V 1.3B (~5GB)
VRAM Before (example: coming from Music Studio)
qwen3:0.6b 0.4G ace-step-1.5 6.1G sdxl-turbo 6.6G
VRAM After (~5GB)
wan-2.1-t2v-1.3b ~5G
Inspire
media-api /video/inspire
● qwen3:0.6b loads on-demand
⚠ Wan + utility coexist (~5.4GB total)
VRAM After
qwen3:0.6b 0.4G wan-2.1-t2v-1.3b ~5G
Generate
gpu-manager /acquire (video, pre_inference)
✕ Evict ALL Ollama models (including qwen3:0.6b)
✓ Wan 2.1 already loaded
VRAM After
qwen3:0.6b evicted -0.4G wan-2.1-t2v-1.3b ~5G
Inference
video-api /generate
● Wan 2.1 generates video frames
● Full VRAM available - no contention
VRAM During Peak
wan-2.1-t2v-1.3b ~5G base, ~10G peak

The utility model (qwen3:0.6b) loads on-demand in ~1s when inspire/naming is called. It's always evicted before actual inference via the pre_inference flag on /acquire. Cover art for video uses a separate /video/cover-art endpoint that loads SDXL Turbo after video generation completes.
